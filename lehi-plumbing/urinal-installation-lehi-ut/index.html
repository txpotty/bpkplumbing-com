    New urinals usually need a permit. New fixtures mean rough-in and final inspections, and commercial jobs often need plans. We pull the permit. Like-for-like swaps may not need one.

    Urinal Brands We Install in Lehi, UT

    Brand choice is mostly about parts support. We recommend brands whose valves and cartridges are easy to get locally, so repairs never wait. We install all of them. Spec sheets come first.

    Flushometer Urinal Installation in Lehi

    Manual flushometers are still the most common setup. Manual valves go on a 3/4 inch line with the control stop tuned and the vacuum breaker at the correct height. Handle side follows the layout. ADA units need the handle within reach.

    Residential Urinal Plumbing in Lehi, UT

    Home urinals use the same rules as commercial ones. The drain is usually 2 inch, the trap is built into the china, the fixture needs a vent within code distance, and the flush valve needs either a 3/4 inch supply or a lower-flow residential valve on 1/2 inch. Permit rules apply too. We check that first.

    Old Urinal Removal and Replacement in Lehi

    Old urinals come off harder than they went on. Rusted bolts and seized valves often have to be cut, so we protect the tile while working. New gaskets always go in. The flange gets cleaned to bare metal.

    Waterless Cartridge Urinals in Lehi

    Each waterless brand uses its own cartridge. Falcon, Waterless Co, Kohler and Zurn units all trap odor differently, and the cartridge or sealing liquid has to be replaced after a set number of uses, which in a busy restroom can mean every few months. We set up a schedule with you. Spare cartridges should stay on site.

    Commercial Urinal Installation in Lehi

    Offices and restaurants want urinals that survive heavy use. Each unit goes on a carrier with new gaskets and stainless bolts, paired with a matched Sloan or Zurn valve. We check partition spacing too. Most codes want 15 inches from centerline to the side.

    Urinal Installation Cost Factors in Lehi, UT

    Carrier work is the biggest cost swing. Reusing a carrier and lines is cheap, while new carriers and pipe runs through finished walls cost more. Sensor valves add a few hundred. We itemize each piece.
