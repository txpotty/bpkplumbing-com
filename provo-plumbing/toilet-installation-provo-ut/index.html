    A key part of any toilet installation is ensuring a proper seal between the toilet and the waste pipe, typically achieved with a wax ring and a secure flange.     Wall-Hung Toilet Installation in Provo, UT

    Wall-hung toilets mount to a steel carrier inside the wall, with the tank hidden behind an access plate. We install Geberit, Grohe and Kohler carrier systems and set the bowl height to your preference. This work is best done during a remodel when the wall is open.
