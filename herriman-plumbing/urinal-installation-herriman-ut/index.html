    ADA-Compliant Urinal Installation in Herriman

    At least one urinal in a public restroom with more than one usually has to be accessible. ADA units need a rim at or below 17 inches, a 13-1/2 inch projection and 30 by 48 inches of clear floor. The flush handle has to be easy to reach. We mark it all during rough-in.

    Rough-In Plumbing for Urinals in Herriman, UT

    Rough-in decides whether the finish goes smoothly. We set the carrier, run a 2 inch waste line to the outlet height on the spec sheet, stub the 3/4 inch supply where the flush valve will land, and tie the vent in before anyone hangs drywall. Inspectors see it open. Then the walls close.

    Drainage and Venting for Urinals in Herriman, UT

    Urinal drains clog with scale, not paper. Urine leaves a hard mineral buildup inside the trap and the drain line, especially on waterless units and low-flow fixtures that send less water through, so we slope the line properly and add a cleanout where we can. Venting stops gurgle and odor. We tie in within code distance.

    American Standard and Kohler Urinal Installation in Herriman

    Sensor Urinal Installation in Herriman, UT

    Sensor valves stop missed flushes and double flushes. Batteries last a few years. Hardwired units need an electrician first.
