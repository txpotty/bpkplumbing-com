    Copper to PEX Conversions in Herriman

    Copper lines can develop pinhole leaks from water chemistry, high velocity and sometimes soil contact under slabs.     Polybutylene Replacement With PEX in Herriman, UT

    Gray polybutylene pipe was common in homes built from the late 1970s through the mid 1990s and is notorious for sudden failures.     Small repairs are possible for handy homeowners, but a full repipe requires proper sizing, support spacing and code compliance. Mistakes behind walls can cause hidden leaks and rejected inspections.

    PEX can be used for outdoor applications like irrigation lines or outdoor spigots, but it needs to be protected from direct UV light, which can break down the material over time. When used outdoors, PEX should always be buried or otherwise shielded.

    While PEX installation can look straightforward, professional installation is strongly recommended, especially for whole-home repipes or main line work.
